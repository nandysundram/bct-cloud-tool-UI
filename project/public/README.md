## Logo File

- Transparent background (PNG format)
- Approximately 200-300px width
- High resolution for crisp display

The logo is currently referenced in:
- App.tsx (navigation and footer)
- Dashboard.tsx (sidebar)

All references use: `/bct-logo.png`
